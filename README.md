# 搶救塗潭焦炭窯｜口述影像

四支口述影片記錄新北市新店區塗潭里一帶的產業、土石流與焦炭窯，以及磺窟戰俘營的地方記憶。訪談攝於 2026 年 9 月 5 日；片中的年代與細節以受訪者口述為準。
